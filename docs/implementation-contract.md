## Auth product details

Development rules: normalized lowercase email; email uniqueness only among password accounts; Google and Apple identities each separate accounts even when email matches, no linking by email. No password creation/reset for social-only accounts. Name up to 50 characters; preregister may omit name, PATCH users/me sets name afterward. Password >=8 with uppercase/lowercase/digit. OTP six digits, 10m TTL, pending12h, 5 incorrect attempts per code; 3 sends TOTAL including initial, 60s cooldown. Exhausted attempts/fourth send invalidate the old challenge. A new preregistration starts a new challenge after the60s mail cooldown, as Development explicitly requires; there is no12h account block. Login five failures ->15m block per email,20/hr/IP. Preregister5/hr/IP; resend10/hr/IP; forgot3/hr/email10/hr/IP. Password reset request email + code + new_password (explicit added address for OTP lookup). Reset revokes all refresh tokens. Registration route canonical Back /preregister; compatibility /pre-register permitted. users/me supports name/timezone, the one-time planning-only or legacy three-module choice described above, and onboarding completion; allow requested plan=free or trial only; never client pro or client trial_ends. Trial activation only when user selects plan=trial, once for72h (detailed onboarding board rules), entitlements check expiry at access. Unselected Free modules locked. No billing endpoints.
